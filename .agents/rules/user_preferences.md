# Custom AI Planning Rules

- **Mandatory Approval Step**: ก่อนลงมือเขียนโค้ด ให้สรุปแผนการแก้ปัญหาเป็นข้อๆ สั้นๆ (ไม่เกิน 3 ข้อ) และหยุดรอให้ User กดยืนยัน (Approve) ก่อนเริ่มแก้โค้ดจริงทุกครั้ง
- ห้ามแก้โค้ดโดยพลการถ้ายังไม่ได้รับ Approve จากแผนนั้นๆ (ยกเว้นการตรวจสอบระบบหรือคำสั่งที่ไม่กระทบโค้ด)
- **Git Push Protocol**: ห้ามทำการ `git push` โดยพลการ จะต้องรอให้ User เป็นคนพิมพ์คำสั่ง "git push" ด้วยตัวเองเท่านั้น
- **Feature Preservation**: เวลาทำอะไรเพิ่มเติม หรือแทรกฟีเจอร์ใหม่ ต้องคำนึงถึงสิ่งที่มีอยู่แล้วเป็นสำคัญ (backward compatibility และ existing layouts/logic) ห้ามทำให้ฟีเจอร์เดิมพังเด็ดขาด
